安装与升级
1. 完全关闭游戏，将 ZIP 完整解压到游戏 Package 文件夹之外，再双击 install.bat。
2. 默认安装到 <PKG>；其他位置：install.bat "X:\路径\Package"。
3. 原版、10-31、11-01 和本版均可直接覆盖安装，无需先卸载。
4. 保留玩家 settings.ini 的已有值，补充缺失默认项；未知自定义键也保留。
   本包默认值基于 11-01：不强制装备伙伴，不启用演示诊断/帧率/VSync 测试。
   charaLevel 与 11-01 一样不设置；已有玩家配置中的值仍保留。
5. 覆盖及移除的旧文件（包括旧 settings.ini）先备份到本包旁的
   backup_before_install_<时间>_<唯一标识>。这是安装前快照，不是原版。
   清理两版旧包已新增但本版不再包含的文件（本次 {obsolete} 个）。
6. 检测到本目录游戏正在运行（或不能确定进程路径）时会拒绝操作。

卸载
双击 uninstall.bat（其他路径也可作同样参数）。从本包 original\ 恢复经校验的
原版文件，移除本版及两版旧包新增的文件。无论之前安装哪一版都可恢复原版；
不依赖旧包旁的备份目录。卸载前另存当前 settings.ini，供人工取回个人设置。
不要用旧版 uninstall.bat 卸载本版。未触及的存档、机器配置和其他文件保留。
